# 🌿 GREEN EARTH – Environmental Awareness

## 🌍 About the Project

**Green Earth** is a website dedicated to promoting environmental awareness, environmental protection, and sustainability.

The website encourages people to take responsibility for protecting our planet through simple everyday actions such as planting trees, saving water, reducing pollution, recycling, and conserving energy.

Its main goal is to inspire everyone to work together toward a cleaner, greener, and healthier future.

## ✨ Features

- **Home Section** – Welcoming introduction with an environmental background.
- **About Section** – Explains the meaning and importance of environmental awareness.
- **Importance Section** – Highlights why protecting nature matters.
- **Eco Tips Section** – Provides simple tips for sustainable living.
- **Take Action Section** – Encourages visitors to participate in protecting the Earth.
- **Dark Mode / Light Mode Toggle** – Allows users to switch between themes.
- **Smooth Scrolling** – Provides smooth navigation between sections.
- **Animations and Hover Effects** – Makes the website more interactive and attractive.
- **Responsive Design** – Adjusts the layout for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **CSS3** – Provides styling, layouts, transitions, and animations.
- **JavaScript** – Handles the dark mode and light mode toggle.

## 🌱 Environmental Goals

This project promotes the following environmental practices:

- Plant more trees.
- Save water.
- Reduce plastic waste.
- Recycle reusable materials.
- Save electricity.
- Practice proper waste segregation.
- Use eco-friendly transportation.

## 🎯 Project Purpose

The purpose of this project is to educate people about environmental awareness and encourage sustainable habits. It demonstrates how web development can be used to share important messages and inspire positive changes in our community.
